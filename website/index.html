Other Windows options

View Microsoft Store listing · Standalone EXE (unsigned)

Some managed computers restrict Store installations. The standalone EXE may show a security prompt.

Use a command 
winget install --id 9PB6H8Z02K0G --source msstore

PowerShell or Command Prompt. Requires WinGet and Store access.

macOS

Mac · Apple Silicon ↓Mac · Intel ↓

macOS 11+ · Signed & notarized. Choose your Mac’s chip.

Use a command 
brew install --cask gopalasubramanium/plainmark/plainmark@preview

Run in Terminal. Requires Homebrew; the “preview” cask installs v0.4.0.

Linux · AppImage

Download AppImage ↓

Linux x64 · Requires WebKitGTK 4.1. Compatibility varies by distribution.

Use a command 
curl -fLO https://github.com/gopalasubramanium/plainmark/releases/download/v0.4.0/Plainmark_0.4.0_amd64.AppImage && chmod +x Plainmark_0.4.0_amd64.AppImage

Requires curl and WebKitGTK 4.1 on x64 Linux. Saves an AppImage in this folder; open the file to run.

Debian / Ubuntu

Download .deb package ↓

Debian / Ubuntu x64 · Requires WebKitGTK 4.1.

Use a command 
curl -fLO https://github.com/gopalasubramanium/plainmark/releases/download/v0.4.0/Plainmark_0.4.0_amd64.deb && sudo apt install ./Plainmark_0.4.0_amd64.deb

Requires curl, apt, and WebKitGTK 4.1 on x64 Debian / Ubuntu. Asks for administrator approval to install.

v0.4.0 · Early release
Installation & release notes

One public baseline across these downloads: v0.4.0. An early release, with known limitations. Previous releases remain available.

The Windows Store installer needs internet and Store access; Microsoft handles its package signing and updates. Mac downloads are publisher-signed and Apple-notarized. Homebrew uses the same Mac downloads from our official tap. Linux packages are built on Ubuntu 22.04 and depend on system libraries.
