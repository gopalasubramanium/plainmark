Prefer a terminal?

Choose the command for your computer and paste it into a terminal.

Windows · PowerShell or Command Prompt

winget install --id 9PB6H8Z02K0G --source msstore

Installs the signed Store edition. Requires WinGet, internet, and Store access. No WinGet? Download the installer.

macOS · Terminal

brew install --cask gopalasubramanium/plainmark/plainmark@preview

Requires Homebrew. Uses our signed, notarized Mac app. The cask’s “preview” name currently installs v0.4.0. Or download the Mac app.

Linux · Download a portable AppImage

curl -fLO https://github.com/gopalasubramanium/plainmark/releases/download/v0.4.0/Plainmark_0.4.0_amd64.AppImage && chmod +x Plainmark_0.4.0_amd64.AppImage

For x64 Linux with curl and WebKitGTK 4.1. Saves v0.4.0 in the current folder; open the downloaded file to run. Compatibility depends on your distribution. See downloads.

Debian / Ubuntu · Install a .deb package

curl -fLO https://github.com/gopalasubramanium/plainmark/releases/download/v0.4.0/Plainmark_0.4.0_amd64.deb && sudo apt install ./Plainmark_0.4.0_amd64.deb

For x64 Debian / Ubuntu with curl, apt, and WebKitGTK 4.1 available. Downloads v0.4.0 and asks for administrator approval to install it. Or download the package.

A note about downloads.

The Windows download installs the Microsoft Store edition and needs internet access. Microsoft handles its package signing and Store updates. Some managed computers restrict Store installations. The alternative standalone EXE is unsigned and may show a security prompt. Mac downloads are publisher-signed and Apple-notarized. Linux compatibility depends on your distribution.
