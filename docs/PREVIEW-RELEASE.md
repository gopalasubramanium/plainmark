Plainmark v0.4.0 public baseline candidate. Includes visual editing, folder workspaces, tabs, Mermaid/math/SVG, isolated runnable HTML, block synchronization, Quick Open, local note links, image insertion, native print/PDF, recovery controls and Open with integration. Free and open source, with no ads, tracking, paid features or required app accounts.

This is an unpublished draft. The ordinary build produces ad-hoc Mac packages and an unsigned Windows EXE. Complete the separate Mac signing/notarization workflow and verify final downloadable artifacts before publication. Microsoft Store handles its own package distribution and signing; Store availability does not sign the separate EXE. Final release notes must report the verified status of each distribution channel.

The baseline establishes consistent version numbering. It remains an early release until the documented platform-readiness criteria are met.
