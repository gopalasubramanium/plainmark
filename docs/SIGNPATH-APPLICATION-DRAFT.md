Plainmark is a free, open-source desktop Markdown viewer and editor for Windows, macOS and Linux. It works with local files, has no ads, accounts, telemetry, subscription tiers or bundled offers, and uses the operating system's webview. We would like trusted Windows signatures so people can install a basic everyday document tool with a clearly identified publisher.

Source and release workflows are public. Versioned builds use committed dependency lockfiles, include upstream license notices, and run editor and native file-access tests. Prepared release verification includes dependency advisory checks, immutable GitHub Action references, checksums and build provenance. The intended Windows signing scope is Plainmark's own application executable and NSIS installer, built from reviewed version tags; production signatures would require maintainer approval.

Before submitting, the maintainer must confirm the Foundation's current terms, MFA on all relevant accounts, the signing team's roles, a private contact address, and the actual release-process controls. Approval and artifact configuration are not assumed. Any Foundation signing-policy credit will be added only after acceptance and according to the approved wording.

Requested support: guidance on onboarding the public GitHub project and configuring signing of the application executable inside the NSIS installer together with the installer itself.
